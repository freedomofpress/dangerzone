# Release notes templates

Copy one of these templates into the body of the draft GitHub release, then
fill in the placeholders. The files live under `dev_scripts/templates/` in the
repository.

## Regular release

`dev_scripts/templates/release-notes-regular.md`:

```markdown
--8<-- "dev_scripts/templates/release-notes-regular.md"
```

## Security release

`dev_scripts/templates/release-notes-security.md`:

```markdown
--8<-- "dev_scripts/templates/release-notes-security.md"
```

The security template mirrors the structure of our
[security advisories](../../advisories/index.md).
