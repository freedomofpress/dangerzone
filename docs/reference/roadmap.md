# Roadmap

Dangerzone's plans are tracked as GitHub milestones. There is no separate
roadmap document: the milestones are the source of truth, and they change as
work progresses.

| Milestone | What it holds |
| --------- | ------------- |
| [0.11.1](https://github.com/freedomofpress/dangerzone/milestone/25) | First bug fix release for Dangerzone 0.11.0. |
| [0.12.0](https://github.com/freedomofpress/dangerzone/milestone/24) | The next feature release. |
| [1.0.0](https://github.com/freedomofpress/dangerzone/milestone/22) | What we want in place before calling Dangerzone 1.0. |
| [Backlog](https://github.com/freedomofpress/dangerzone/milestone/11) | Technical debt that we need to pay off, or important issues that we need to tackle at some point. |
| [Evergreen](https://github.com/freedomofpress/dangerzone/milestone/23) | The milestone that's always active, tracking long-term changes, not directly related to a specific version. |

The [milestones page](https://github.com/freedomofpress/dangerzone/milestones)
always has the current list, with progress. Larger efforts are tracked as
issues labelled [epic](https://github.com/freedomofpress/dangerzone/issues?q=is%3Aissue+is%3Aopen+label%3Aepic).

If you want to help, [Contribute to Dangerzone](../how-to/contribute.md)
explains how to pick something up.
