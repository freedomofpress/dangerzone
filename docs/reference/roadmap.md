# Roadmap

Dangerzone's plans are tracked as GitHub milestones. There is no separate roadmap document: the milestones are the source of truth, and they change as work progresses.

| Milestone | What it holds |
| --------- | ------------- |
| [X.Y.Z](https://github.com/freedomofpress/dangerzone/milestone/25) | 0.11.0 for instance here. |
| [1.0.0](https://github.com/freedomofpress/dangerzone/milestone/22) | What we want in place before calling Dangerzone 1.0. |
| [Backlog](https://github.com/freedomofpress/dangerzone/milestone/11) | Technical debt that we need to pay off, or important issues that we need to tackle at some point. |
| [Evergreen](https://github.com/freedomofpress/dangerzone/milestone/23) | The milestone that's always active, tracking long-term changes, not directly related to a specific version. |

The [milestones page](https://github.com/freedomofpress/dangerzone/milestones) always has the current list, with progress. Larger efforts are tracked as issues labelled [epic](https://github.com/freedomofpress/dangerzone/issues?q=is%3Aissue+is%3Aopen+label%3Aepic).

If you want to help, pick up an issue labelled [good first issue](https://github.com/freedomofpress/dangerzone/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) or [help wanted](https://github.com/freedomofpress/dangerzone/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22).
