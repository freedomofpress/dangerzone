# Tutorials

Tutorials take you through a complete, small task from start to finish, so that
you learn by doing. They assume nothing beyond what they state at the top, and
they avoid choices and detours: follow the steps in order and you end up with a
working result.

If you already know what you want to achieve and only need the steps, look at
the [how-to guides](../how-to/index.md) instead.

<div class="grid cards" markdown>

-   __[Convert your first document](convert-your-first-document.md)__

    ---

    Install Dangerzone, open a suspicious file, and get a safe PDF out of it
    using the graphical application.

-   __[Convert documents from the command line](convert-from-the-command-line.md)__

    ---

    Use `dangerzone-cli` to convert one or many documents from a terminal,
    with character recognition.

-   __[Run Dangerzone from source](run-dangerzone-from-source.md)__

    ---

    Set up a development checkout on Ubuntu or Debian, run the application
    and its tests, and make a first change.
